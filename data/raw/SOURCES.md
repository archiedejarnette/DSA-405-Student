# Raw Data Sources

- `tmdb_raw.json` — Movie data collected from The Movie Database (TMDB) API.
  - Movie discovery endpoint: https://api.themoviedb.org/3/discover/movie
  - Movie details endpoint: https://api.themoviedb.org/3/movie/{movie_id}
  - Collected: 9/18/2026
    
The raw file is approximately 433 MB and exceeds GitHub's 100 MB file-size limit. Following instructor guidance, the raw file is submitted separately with the assignment rather than stored in this repository.
